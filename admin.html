Running things from the Sheet

  • Add a privilege (free entry, discount, media link, file): add a row on the privileges tab. Kind is free, discount, link or file. Then use the Sheet menu Parivar Pass → Set up / sync to add its column to passes.
  • Bulk actions: on the passes tab, filter the rows you want and fill the privilege column with enabled, used or disabled. A blank cell means that privilege's default.
  • Staff access: add a row on the staff tab with a name, a PIN and a role (checker or admin). Set active to FALSE to revoke. Checkers can only mark privileges used; admins can do everything.
  • Cancel a pass: set its status to void. Every desk action lands on the log tab.
